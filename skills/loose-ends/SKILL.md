# Loose ends

Reread the thread from the start. List every request, every commitment you made, and every follow-up you deferred. Check each against current state, not memory: the working tree, unpushed commits, PRs, CI, background tasks, and any agent or thread you started.

If nothing is open, say so in one line. Otherwise, number the open items and say why each is open. Finish the ones that don't need the user, then step through the rest one at a time, with the context needed to decide and your recommendation. Finish when every item is done or the user has decided it.
